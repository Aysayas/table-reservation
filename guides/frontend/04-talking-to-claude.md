# 4. Paano kausapin si Claude

Mas maganda yung gawa ni Claude kapag **specific** ka. Sabihin mo kung *anong screen*, *anong part*, at *ano yung gusto mo*.

| 😕 Malabo | 😊 Malinaw |
|---|---|
| "ayusin mo" | "Sa screen 03, ang liit ng Reserve button. Gawin mong full width gaya sa wireframe." |
| "sira" | "May error pag nira-run ko yung app: (i-paste yung error)" |
| "pagandahin mo" | "Sa screen 01, lagyan mo ng mas malaking space between yung title at yung buttons." |
| "gawin mo lahat ng admin pages" | `/build-screen 19` (isa-isa lang) |

## Mga message na pwede mong i-copy

**Pagsimula ng araw**
```
Good morning! What's my progress, and which screen should I do next?
```

**Pag-aaral**
```
Explain what you just did like I'm a beginner.
```
```
Ano yung "component"? Pakita mo yung isa sa project natin.
```

**May mukhang mali**
```
Screen 08 looks different from the wireframe. Compare them and tell me what's different.
```

**May error**
```
May lumabas na error, ano ibig sabihin nito at paano natin aayusin?
(i-paste dito yung error, o i-drag yung screenshot)
```

**Undo**
```
Undo the last change you made. Mas okay yung dati.
```

**Check ng work**
```
/check-my-work
```

**Pagtapos ng araw**
```
Summarise what I did today in 3 bullets for my team.
```
