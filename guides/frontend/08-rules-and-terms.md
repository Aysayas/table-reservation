# 8. Rules at terms

## Golden rules

✅ **Gawin**
- Isang screen lang at a time
- I-compare lagi sa wireframe
- Magtanong ng "bakit?" kahit kailan
- I-run ang `/check-my-work` bago mo sabihin sa team na tapos ka na
- Sabihan ang team kung anong screen yung ginagawa mo

❌ **Huwag**
- Gamitin yung totoong pangalan ng tao, phone number, email o food pictures. Gamitin yung `Juan Dela Cruz`, `09XX XXX XXXX`, `placeholder-domain.com`, at gray boxes. (Okay lang yung totoong pangalan ng restaurant, logo, menu at presyo: nasa `sampleData.ts` na sila)
- Magdagdag ng pages o features na wala sa wireframes
- Galawin yung backend o settings files
- Mag-paste ng passwords o secret keys sa chat o sa code
- Mag-click ng "Allow" sa hindi mo naiintindihan. Magtanong muna

## Mini dictionary

| Word | Ibig sabihin |
|---|---|
| **Screen / page** | Isa sa 29 drawings, ginawang web page |
| **Wireframe** | Yung drawing ng layout ng screen |
| **Component** | Reusable na building block, parang LEGO piece (button, menu card) |
| **Route / URL** | Yung web address ng page, gaya ng `/menu` |
| **Placeholder** | Temporary na page ("Screen 07 · About Us") habang wala pa yung totoo |
| **Sample data** | Fake na menu items o reservations para may maipakita yung page |
| **Tailwind** | Yung paraan natin ng pag-style, gamit yung maiikling words gaya ng `p-4` (padding) o `font-bold` |
| **Frontend / backend** | Yung nakikita mo / yung hidden part na nagse-save ng data |
| **Error** | Message na may nagkamali. Hindi nakakatakot, i-paste mo lang kay Claude |
| **Terminal** | Yung black na window kung saan tumatakbo yung commands. Si Claude ang gumagamit nito para sa'yo |
