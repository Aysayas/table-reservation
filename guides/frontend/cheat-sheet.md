# ⭐ Cheat sheet

| Gusto mong… | I-type 'to |
|---|---|
| Magsimula ng screen | `/build-screen 07` |
| I-check lahat | `/check-my-work` |
| Malaman kung ano next | `What should I do next?` |
| Maintindihan ang isang bagay | `Explain ___ like I'm a beginner` |
| Ipaayos ang isang bagay | `Sa screen NN, yung ___ dapat ___` |
| Mag-undo | `Undo the last change` |
| Mag-report ng error | `I got this error: (paste)` |
| Humingi ng exception sa lead | `Please note it for the lead` |
| I-save ang progress | `Save my work` |
| I-send ang tapos na screen | `Open a pull request for this screen` |
| Kunin ang changes ng teammates | `Get the latest changes from main` |
| Ayusin ang red ❌ sa pull request | `My pull request has a red X. What's wrong?` |

## Daily routine

1. Buksan ang Claude → **Code** tab → session sa `table-reservation` folder
2. `Get the latest changes from main`
3. `What should I do next?`
4. `/build-screen NN`
5. `/check-my-work`
6. `Open a pull request for this screen`

Kaya mo 'to! 💪
