# 2. Claude basics

Si Claude ay parang sobrang bilis na assistant. Kaya niyang magbasa ng files, magsulat ng code, at mag-run ng commands, pero **kapag inutos mo lang**.

## Mga dapat mong malaman

- **Alam na ni Claude yung rules ng project.** May file na `CLAUDE.md` na binabasa niya tuwing magsisimula ang session. Nandun yung design, colors, order ng trabaho, at kung ano ang hindi niya dapat galawin. Hindi mo na kailangang i-explain yung project every time.

- **Magpapaalam si Claude** bago mag-run ng ibang commands o mag-edit ng files. May lalabas na box na may buttons:
  - Kung tungkol sa project 'to (building, testing, pag-edit ng files sa `frontend/`), click mo lang **Allow**.
  - Kung hindi mo gets kung ano yung hinihingi niya, **huwag mo munang i-click**. I-type mo: *"What does this do? Explain simply."*

- **Nagkakamali din si Claude.** Lagi mong i-check yung result sa browser. Ikaw ang magde-decide kung tama na ba.

- **Pwede kang magtanong ng kahit ano.** "Ano yung component?", "Bakit mo ginawa 'yan?", "Explain mo 'tong error na parang beginner ako". Walang tanong na nakakahiya dito.

- **Pwede kang mag-type in English, Tagalog, o Taglish.** Gets ka niya either way.
